## About <a name = "about"></a>

This repository provides the accompanying demo and reproducibility materials for the paper:

> A Privacy-Preserving and User-Participatory Load Data Aggregation Framework in IoT-Based Cloud-Edge-End-User Power System Architecture

## Project Structure

```text
P2UPDAF/
├── experiments-and-results/
│   ├── run_experiment.py     # Experiment and visualization entry point
│   ├── code/                 # Experiment implementation and supporting code
│   ├── data/                 # Dataset files or dataset acquisition notes
│   ├── results/
│   │   ├── logs/             # Experiment logs
│   │   └── tables/           # Tabular results and metrics
│   ├── visualizations/       # Generated plots and visual outputs
│   ├── environment.yml       # Experiment environment dependencies
│   └── README.md             # Experiment and results overview
└── paper-latex-source/       # LaTeX source files for the paper
```

See the `README.md` in each folder for details about its contents and intended use.
