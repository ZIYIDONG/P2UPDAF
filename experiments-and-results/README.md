# Experiments and Results

This folder contains the code, data, and outputs used to reproduce the experiments reported in the paper.

- `run_experiment.py`: the entry point for running experiments and generating visualizations.
- `code/`: reusable experiment implementation and supporting code called by the entry point.
- `data/`: datasets or instructions for obtaining and preparing them.
- `results/`: generated experiment outputs, including logs and tables.
- `visualizations/`: plots and other visual outputs generated from experiment results.
- `environment.yml`: the Conda environment specification for the experiments.

See the README in each subfolder for more specific guidance. Do not commit large or restricted datasets unless their licenses and repository hosting arrangements permit it.
